보컬 결합 스튜디오

여러 보컬을 한 트랙으로 결합

오디오 파일을 트랙에 끌어다 놓고 볼륨·팬·피치를 조정한 뒤, 한 번에 재생하거나 WAV로 내보내세요. 모든 처리는 브라우저 안에서 이루어집니다.

빠른 사용법

  1. 각 트랙의 빈 영역을 클릭하거나 오디오 파일을 끌어다 놓아 클립을 불러옵니다 (.wav, .mp3, .m4a, .ogg).
  2. 트랙별 볼륨·팬·피치를 조정합니다.
  3. Space 또는 재생 버튼으로 동시 재생, 내보내기로 WAV를 저장합니다.
  4. 필요하면 하단의 + 트랙 추가로 트랙을 더 늘릴 수 있습니다.
