# dobedupop MVP 데모 가이드 — Dynamite 2차 이용

BTS "Dynamite" 2차 이용을 빅히트 뮤직 테넌트·멤버·운영자가 각자 로그인해 권리 등록부터 지급까지 보여 준다. 가상 사례다. 곡 크레딧(작사·작곡 David Stewart·Jessica Agombar)·멤버·가창 시간만 실제이고, 지분·계약·가격·판매량은 가정이다.

## 띄우기

```bash
cd 06_MVP/dobedupop
cp deploy/env/demo.env.example deploy/env/demo.env     # 처음 한 번. RC_DOC_KEY: openssl rand -base64 32
docker compose -f deploy/compose/compose.demo.yml --env-file deploy/env/demo.env up -d --build
```

| 주소 | 화면 |
| --- | --- |
| http://demo.dobedupop.localhost | 데모 진행판(단계 실행·페르소나로 앱 열기) |
| http://portal.dobedupop.localhost | 권리자 포털 |
| http://artist.dobedupop.localhost | 실연자 앱(휴대폰 화면 크기로 보면 좋다) |
| http://ops.dobedupop.localhost | 운영 백오피스 |

`*.localhost` 주소는 hosts 파일 없이 이 컴퓨터로 연결된다(Chrome·Edge·Firefox). Safari에서 열리지 않으면 Chrome을 쓴다.

## 진행

1. 데모 진행판에서 **처음부터 다시** → 단계를 하나씩 **실행**하거나 **남은 단계 모두 실행**. 전체 실행은 약 3~4분이다(3월 구매 2,201건을 넣고, 지급은 가상 PSP가 1분 뒤 완료 통지).
2. 각 단계 카드의 버튼(예: "포털: 권리 요약")을 누르면 그 단계를 보여 줄 앱이 그 페르소나로 로그인된 채 새 탭에 열린다.
3. 오른쪽 "페르소나로 앱 열기"에서 사람을 바꿔 본다. 같은 데이터를 사람마다 다르게 보는 것(테넌트 격리·역할)이 시연 포인트다.

가상 시계는 단계마다 앞으로 간다(1/1 온보딩 → 2/1 정책 활성화 → 2/15 발행 → 4/1 정산 → 5/1 지급).

## 페르소나

| 사람 | 앱 | 볼 것 |
| --- | --- | --- |
| 빅히트 권리 편집(`usr_bh_rights`) | 포털 | 권리 요약(문장 + 근거 문서), 원천 문서, 확인 요청, 표준 계약, 정합성 점검, 발행 조회, 명세(레이블·소속사) |
| 빅히트 정책 편집·승인·활성화 | 포털 | 분배 규칙 — 세 사람이 나눠서 편집·승인·활성화 |
| 정국·진 등 멤버(`usr_member_*`) | 실연자 앱 | 동의·계약 서명, 내 목소리가 쓰인 조합, 수익(위임 전 내 기여분), 알림 |
| 운영(`usr_ops`) | 운영 | ⑧ 파이프라인 관제(이상거래 1건 보류 등), 한 건 추적, 확인 요청(작가 지분 원문 대조) |
| 정산 담당(`usr_settle`) | 운영 | 정산 배치(실행 → 독립 재계산 → 확정), 원장, 지급 run, 명세 |
| 플랫폼 온보딩 담당(`usr_rights`) | 운영 | 파티 등록, 해외 작가와의 작품 이용허락 |

데모 환경에만 페르소나 빠른 로그인이 있다. 실제 로그인(운영 = 비밀번호 + 인증 앱 코드, 포털 = 비밀번호, 실연자 = 본인 인증 코드)도 같은 화면에서 된다. 운영 계정 발급·초대는 운영 백오피스 API(`/users`)로 한다.

## 온보딩 화면(운영 백오피스 → 9 관리)

| 화면 | 할 수 있는 일 |
| --- | --- |
| 테넌트(온보딩) | 테넌트 목록(유형·상태·계정 수·당사자 수·정합성 차단 적용), 테넌트 등록(id·이름·유형) |
| 테넌트 상세(예: 빅히트 뮤직) | 계정 목록(역할·로그인 준비 상태·마지막 로그인), 담당자 계정 만들기 → 초대 링크, 역할 변경, 잠금·해제, 초대 링크 다시 만들기, 당사자 목록·등록 |
| 계정 | 전체 계정(소속으로 거르기), 플랫폼 인력·실연자(개인) 계정 만들기 |

권리자 포털의 "내 테넌트"에서는 우리 테넌트 정보·당사자·계정을 읽기 전용으로 본다(계정 발급·역할 변경은 플랫폼 운영에 요청). 데모 페르소나 계정은 빠른 로그인으로 들어가므로 계정 목록에 "초대 수락 대기"로 보인다 — 실제 비밀번호 로그인을 보려면 "초대 링크 다시 만들기"로 링크를 받아 비밀번호를 정한다.

## 지금의 한계

- 시연 단계는 데모 진행판이 API로 실행한다. 같은 일을 화면에서 직접 해 볼 수도 있지만(예: 새 곡 등록), 단계 진행과 섞으면 진행판이 상태를 모른다 — 그럴 때는 "처음부터 다시".
- 4월 감상 매출(재생 비중 배정)과 동의 철회·노출 중지 시연 단계는 아직 진행판에 없다.
- 개발용 PSP의 실패 주입(지급 실패 시연)은 역할을 나눈 데모 스택에서 워커에 닿지 않는다.
