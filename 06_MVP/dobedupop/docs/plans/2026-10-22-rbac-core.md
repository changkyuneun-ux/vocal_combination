# 총괄 운영과 권한 구조 1부(코어 RS1~RS4) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 코어의 역할 검사를 "기능 → 권한 → 역할"(DB RBAC)로 바꾼다. 직무 분리는 규칙 목록으로 모아 끈다. 총괄 한 계정이 플랫폼·권리 테넌트·참여 기관 소속으로 모든 기능을 쓸 수 있게 한다.

**Architecture:** 권한 목록은 코드 상수(`src/platform/permissions.ts`)가 정의하고, 마이그레이션이 같은 내용을 `permission` 표에 넣는다(시험이 둘을 대조한다). 역할(`role`)과 역할–권한(`role_permission`)은 DB가 원본이다. 배정 표는 지금의 `portal_role`을 그대로 쓰고, `role` 표를 외래키로 가리키게 바꾼다. `loadActor`가 현재 소속의 권한 집합을 `actor.permissions`에 담고, 코어 95곳의 `requireRole`/`requireAnyRole`/`roles.has`를 `requirePermission`/`hasPermission`으로 바꾼다. 지금 역할 15종은 `legacy` 역할로 남아 지금과 같은 권한을 가지므로, 기존 시험이 그대로 통과해야 한다.

**Tech Stack:** Node 24(TypeScript 직접 실행), Fastify 5, PostgreSQL(RLS), `node:test`. 시험 DB는 `test/helpers.ts`의 `freshDb()`(템플릿 DB 복제, 앱 역할 `rc_app`)

**설계 문서:** [총괄 운영과 권한 구조](../../../../00_프로젝트_개요/총괄_운영과_권한_구조_20261022.md). 2부(콘솔·시드·관리 화면·E2E, RS5~RS8)는 이 계획이 끝난 뒤 따로 쓴다.

`test/platform/rbac.test.ts`:

```ts
import { test, after } from "node:test";
import assert from "node:assert/strict";
import pg from "pg";
import { freshDb } from "../helpers.ts";
import { PERMISSIONS, ALL_PERMISSIONS } from "../../src/platform/permissions.ts";

// 기능–권한–역할(총괄 운영과 권한 구조 RS1): 코드의 권한 목록과 DB가 같고, 지금 역할은 legacy 역할로 같은 권한을 갖는다.
const { db, adminUrl, drop } = await freshDb();
after(drop);

test("permission table matches the code catalog", async () => {
  const rows = (await db.pool.query("SELECT perm_id, area, kind, org_classes, assignable FROM permission ORDER BY perm_id")).rows;
  assert.deepEqual(rows.map((r) => r.perm_id), [...ALL_PERMISSIONS].sort());
  for (const r of rows) {
    const p = PERMISSIONS[r.perm_id as keyof typeof PERMISSIONS];
    assert.deepEqual({ area: r.area, kind: r.kind, orgClasses: [...r.org_classes].sort(), assignable: r.assignable },
      { area: p.area, kind: p.kind, orgClasses: [...p.orgClasses].sort(), assignable: p.assignable }, r.perm_id);
  }
});

test("legacy roles carry exactly the permissions of today's role checks", async () => {
  const rows = (await db.pool.query("SELECT rp.role_id, rp.perm_id FROM role_permission rp JOIN role r USING (role_id) WHERE r.legacy")).rows;
  const got = rows.map((r) => `${r.role_id}:${r.perm_id}`).sort();
  const want = ALL_PERMISSIONS.flatMap((p) => PERMISSIONS[p].legacy.map((role) => `${role}:${p}`)).sort();
  assert.deepEqual(got, want);
});

test("a role of one org class cannot take a permission of another, nor be given in another org", async () => {
  const c = new pg.Client({ connectionString: adminUrl });
  await c.connect();
  try {
    await c.query("INSERT INTO role (role_id, name, org_class) VALUES ('T_PLATFORM', '시험', 'PLATFORM')");
    await assert.rejects(c.query("INSERT INTO role_permission VALUES ('T_PLATFORM', 'policy.approve')"), /ROLE_CLASS_MISMATCH/);
    await assert.rejects(c.query("INSERT INTO role_permission VALUES ('T_PLATFORM', 'revenue.ingest')"), /PERMISSION_NOT_ASSIGNABLE/);
    await c.query("INSERT INTO role_permission VALUES ('T_PLATFORM', 'settlement.confirm')");
    await assert.rejects(c.query("INSERT INTO portal_role (user_id, tenant_id, role) SELECT user_id, tenant_id, 'T_PLATFORM' FROM user_membership m JOIN tenant t USING (tenant_id) WHERE t.org_class = 'RIGHTS' LIMIT 1"), /ROLE_CLASS_MISMATCH/);
    await assert.rejects(c.query("INSERT INTO portal_role (user_id, tenant_id, role) VALUES ('sys_ingest', 'tnt_platform', 'NO_SUCH_ROLE')"), /foreign key/);
  } finally {
    await c.end();
  }
});
```

```ts
import type { Actor } from "./actor.ts";
import { DomainError } from "./errors.ts";

export function hasPermission(actor: Actor, perm: Permission): boolean {
  return actor.permissions.has(perm);
}

/** 권한이 없으면 403 ROLE_REQUIRED(코드는 역할 검사 때와 같다 — 화면·시험이 이 코드를 본다). */
export function requirePermission(actor: Actor, perm: Permission): void {
  if (!actor.permissions.has(perm)) throw new DomainError("ROLE_REQUIRED", 403, `${actor.userId} lacks permission ${perm}`);
}

/** 권한 중 하나라도 있으면 통과한다. */
export function requireAnyPermission(actor: Actor, perms: readonly Permission[]): void {
  if (!perms.some((p) => actor.permissions.has(p))) throw new DomainError("ROLE_REQUIRED", 403, `${actor.userId} lacks any of permissions ${perms.join(", ")}`);
}

/** 권한을 더한 행위자 사본. 시스템 대행(팬 대신 발행, 수집 시스템 대신 매출 기록)에만 쓴다. */
export function withPermissions(actor: Actor, extra: readonly Permission[]): Actor {
  return { ...actor, permissions: new Set([...actor.permissions, ...extra]) };
}
```

```ts
export async function setSodRules(adminUrl: string, rules: readonly SodRule[] | "all", enabled = true): Promise<void> {

  await c.connect();
  try {
    if (rules === "all") await c.query("UPDATE sod_rule SET enabled = $1", [enabled]);

  } finally {
    await c.end();
  }
}
```

```ts
      WHERE r.role = 'PLATFORM_ALL' AND r.tenant_id = $1 AND u.disabled_at IS NULL`, [PLATFORM_TENANT])).rows.map((x) => x.user_id as string);
  if (holders.length === 1 && holders[0] === userId) throw conflict("LAST_SUPER_ADMIN", `${userId} is the last platform super administrator`);
}
```

`setRoles`에서 `before`를 읽은 뒤 `if (before.includes("PLATFORM_ALL") && !next.includes("PLATFORM_ALL")) await assertNotLastSuperAdmin(tx, userId);`를 넣는다. `setDisabled`에서는 `UPDATE` 전에 `if (disabled) await assertNotLastSuperAdmin(tx, userId);`를 넣는다. `PLATFORM_TENANT`는 `./actor.ts`에서 import하고, `conflict`가 import돼 있는지 확인한다.

`src/platform/super-admin.ts`:

```ts
import type { Clock } from "./clock.ts";
import type { Tx } from "./db.ts";
import { createUser, PLATFORM_TENANT, withSystemScope, type OrgClass, type Role } from "./actor.ts";
import { invalid } from "./errors.ts";
import { audit } from "./audit.ts";

const SUPER: Partial<Record<OrgClass, Role>> = { RIGHTS: "RIGHTS_ALL", PARTICIPANT: "PARTICIPANT_ALL" };

/**
 * 총괄 계정(결정 RD1): 플랫폼 기본 소속에 PLATFORM_ALL, 각 조직(권리 테넌트·참여 기관) 소속에 그 구분의 총괄 역할. 여러 번 불러도 같다.
 * 데모·MVP 운영 시드가 부른다. 로그인은 운영과 같다(비밀번호 + TOTP, 결정 RD7).
 */
export async function ensureSuperAdmin(tx: Tx, clock: Clock, a: { userId: string; displayName: string; tenantIds: readonly string[] }): Promise<void> {
  await withSystemScope(tx, async () => {
    if ((await tx.query("SELECT 1 FROM user_account WHERE user_id = $1", [a.userId])).rowCount === 0) {
      await createUser(tx, clock, { userId: a.userId, displayName: a.displayName, roles: ["PLATFORM_ALL"], tenantId: PLATFORM_TENANT });
      await audit(tx, clock, { actor: a.userId, action: "SUPER_ADMIN_CREATE", entityType: "user_account", entityId: a.userId });
    }
    for (const tenantId of a.tenantIds) {
      const t = (await tx.query("SELECT org_class FROM tenant WHERE tenant_id = $1", [tenantId])).rows[0];
      const role = t === undefined ? undefined : SUPER[t.org_class as OrgClass];
      if (role === undefined) throw invalid("BAD_REQUEST", `${tenantId} is not a rights tenant or participant organization`);
      await tx.query("INSERT INTO user_membership (user_id, tenant_id, added_by, added_at) VALUES ($1,$2,$1,$3) ON CONFLICT DO NOTHING", [a.userId, tenantId, clock.now()]);
      await tx.query("INSERT INTO portal_role (user_id, tenant_id, role) VALUES ($1,$2,$3) ON CONFLICT DO NOTHING", [a.userId, tenantId, role]);
    }
  });
}
```
