# dobedupop 화면 디자인 가이드 — 캔버스 시안 엄격 준수

- 작성일: 2026-10-23
- **기준(원본):** 캔버스 시안 https://claude.ai/artifact/Gg8EKnnnXcBan6nBcfpf6k (파일 `06_MVP/mockup/console/project/*.dc.html`)
- 이 문서는 시안에서 뽑은 값이다. 시안과 이 문서가 다르면 **시안이 이긴다.** 앱의 기존 공통 테마(`packages/ui/theme.css`, 이전 목업 M0a 기준)와 다르면 **시안이 이긴다.**

## 1. 지킬 규칙

1. **화면은 시안 그대로 만든다.** 구조(영역 배치·순서), 문구, 색, 글자 크기·굵기, 간격, 테두리·모서리, 상태 표시(배지·막대·칸 색)를 시안의 인라인 스타일 값과 같게 맞춘다. "앱의 기존 컴포넌트로 비슷하게"는 허용하지 않는다. 기존 컴포넌트가 시안과 다르면 컴포넌트를 시안에 맞게 고치거나 새로 만든다
2. **시안에 없는 요소를 더하지 않는다.** 꼭 필요하면(API 제약 등) 먼저 시안을 고쳐 승인받고 구현한다. 시안에 있는데 구현하지 못한 것은 빈칸으로 숨기지 말고 보고에 적는다
3. **구현 뒤 반드시 시안과 나란히 비교한다.** 같은 화면을 브라우저로 열어 시안 보드와 같은 폭(1440px)에서 스크린샷을 찍고, 영역별 차이 목록을 만든다. 차이가 0이 될 때까지 고친다. 비교 스크린샷과 차이 목록을 보고에 붙인다
4. **보고에 "시안 준수"를 따로 쓴다.** 화면마다 일치·차이·이유를 표로 적는다
5. 색은 아래 토큰으로만 쓴다(화면 코드에 hex를 흩지 않는다). 시안에 새 색이 나오면 먼저 토큰을 더한다

- **상단 머리글 한 줄(가로 메뉴 없음):** `dobedupop`(16px 굵게) · 조직 선택(`빅히트 뮤직 ▾`, `#dbeafe`) · 소속 배지(`권리 테넌트`, 13px, `#1d4ed8` 바탕, 999px) · 오른쪽에 `/ 검색`(13px `#dbeafe`)·데모 시계(Mono, `#92400e` 바탕)·사용자. 머리글 안쪽 여백 `12px 24px`, 간격 `16px`

  - 한 곡 화면과 여러 곡 모아 보기가 함께 있는 기능(확인·동의 · 문서·계약 · 정합성 점검)은 두 곳 모두에 둔다. 워크스페이스는 그 곡을 처리하고, 운영 관리는 모아 보고 곡 워크스페이스로 이동만 한다(시안 `Nav-Ops-Confirm.dc.html`)

## 6. 비교 확인 절차(구현마다)

1. 시안 캔버스에서 그 보드를 연다(포커스 보기, 폭 1440)
2. 구현 화면을 같은 폭으로 연다(같은 데이터 시점 — 시안의 데모 시계 날짜)
3. 두 스크린샷을 영역별로 비교: 머리글 · 경로·준비 띠 · 제목 줄 · 탭 · 본문 카드 순서 · 표 열 · 배지 색 · 버튼 모양·위치 · 문구
4. 차이 목록을 만들고 고친다. 0이 될 때까지 반복
5. 보고: 화면별 "시안 준수" 표 + 비교 스크린샷 경로
