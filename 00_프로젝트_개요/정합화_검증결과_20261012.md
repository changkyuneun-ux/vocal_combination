# dobedupop 정합화 검증 결과

- 기준일: 2026-10-12.
- 사용자 확정 범위: 정리와 통합 설계 확정까지. Grant·프로파일의 발행/정산 런타임 연결은 후속 개발.

## 1. 반영 사항

- 플랫폼 설계 폴더와 최신 HTML 시안 이름을 dobedupop으로 변경.
- 루트 workspace·lockfile·현재 안내 문서·콘솔 제목의 플랫폼 표기 정합화.
- 문서 기준을 사업 목적·언어 목표·실행 API·설치 DB·UI 요구사항으로 구분.
- 개요의 잘못된 팬→Backoffice·Grant 실행 시퀀스를 현재 실행 구조로 수정.
- MDRL 레퍼런스북 8장을 실제 exports·필수 입력·Result 처리 기준으로 개정.
- `mdrl/grant`, `mdrl/profiles` 공개 export 추가 및 tarball 소비 시험 보강.
- 테스트의 undefined 가능성 오류 6건 수정. 검증 단언으로 오류 배열 존재를 확인하고 진단 접근을 안전하게 처리.
- 실행 가능한 `mdrl/samples/public-api.mjs` 추가. Allocation 재현 결과와 Grant 누락 거부를 독립 검증.
- Grant·제품 프로파일의 그래프 요구 도출, 수권·공동권리자, 의무, 봉인, 신규 DB/API, 철회·격리·인수 기준 확정.
- HTML의 49개 화면을 React·서버 API·테이블·관련 시험과 대응.

## 2. 실행 검증

아래 명령의 실행 위치는 `04_구현_소스코드`다.

| 검증 | 결과 |
|---|---|
| `npm test -w mdrl` | 300/300 통과 |
| `npm test -w backoffice` | 11개 파일, 73/73 통과 |
| `npm run typecheck --workspaces` | mdrl·rights-core·backoffice 모두 통과 |
| `npm run build -w mdrl` | 통과 |
| `node mdrl/samples/public-api.mjs` | profile 조회, Grant DENY, Allocation 10개 라인·보류 0, 재검증 통과 |
| `npm run smoke -w mdrl` | tarball 설치·여섯 공개 진입점·타입 선언·CLI 검증 통과 |
| `npm run build -w backoffice` | 타입 검사·Vite 빌드 통과 |
| 문서 링크·파일 이동 무결성 | 루트·개요·API·신규 설계 문서의 로컬 링크 67개, HTML 화면 49개 대응, 이동 파일 41개 확인 |

- 공개 API 예제와 tarball 시험의 Allocation digest: `mdrl:sha256:dd7903d9546713b89868eabdffb2fbb6e0d47b2637bc50e212143dee8d31682b`.
- export 누락은 설치한 tarball의 `ERR_PACKAGE_PATH_NOT_EXPORTED`로 재현 후 보완.
- 전체 시험에서 기존 package 계약 테스트가 새 export를 기대하지 않아 1건 실패했으며, 공개 모듈 목록을 확장한 뒤 300개 전체 재실행 통과.
- npm 기본 캐시가 쓰기 제한되어 smoke에는 `npm_config_cache=/private/tmp/dobedupop-npm-cache` 적용. 사용자 캐시 권한은 변경하지 않음.

## 3. 보존 확인

- 이동한 플랫폼 설계 파일 41개 모두 존재.
- 38개는 Git 원본과 바이트 동일. 최신 Markdown 3개는 `dobedupop → dobedupop` 치환만 확인.
- 역사 자료·Word·PDF 본문과 기존 정산 봉인 형식은 보존.
- 참조문서 대장의 경로는 이동한 파일을 가리키도록 갱신.
- Git 미스테이징 상태에서는 이전 경로 삭제와 새 경로 untracked로 보일 수 있음. 파일 이동이며 원본 유실이 아님.

## 4. 검증 범위와 후속 구현

- 이번 작업에서는 PostgreSQL 서버 통합 시험·브라우저 E2E를 실행하지 않음. 서버 업무 코드·마이그레이션·발행·정산 동작은 변경하지 않음.
- 신규 Grant API·테이블·제품 프로파일·발행/정산 gate는 설계만 반영. 현재 구현됐다고 표시하지 않음.
- 공통 프로파일에는 PUBLISHER·CMO가 남아 있음. dobedupop 제품 프로파일에서 제외하도록 설계했으며 현재 전역 enum 삭제는 하지 않음.
- 기존 참조 대장에 있는 `음악 컨텐츠 관리.pptx`, `프레젠테이션11.pptx`, `프레젠테이션30.pptx`는 현재 폴더에서 찾지 못함. 이번 이동과 관계없는 기존 누락이며 링크를 임의의 다른 파일로 연결하지 않음.
- 과거 VCRL 데이터가 저장된 DB의 호환 이전, 실제 인증·실지급·다중 테넌트 검증은 후속 범위.
