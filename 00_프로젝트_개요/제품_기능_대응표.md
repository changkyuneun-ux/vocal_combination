# dobedupop 제품 기능 대응표

- 기준일: 2026-10-12. 소스 정적 대조 기준이며 전체 화면의 실행 검증 완료를 의미하지 않음.
- HTML 시안은 요구사항 표현, React는 별도 API 연결 구현. 화면 수·버전 숫자로 구현률을 계산하지 않음.
- 연결: 해당 핵심 업무 흐름의 UI/API/저장 연결 존재. 부분: 유사 기반 기능은 있으나 시안 범위와 다름. 미구현: 직접 대응 경로 없음.
- 아래 테스트는 **관련 시험 소스**이며 각 HTML 화면의 기능 전체를 검증하는 시험이 아니다. 실행 결과는 [검증 기록](정합화_검증결과_20261012.md)에 별도 기록.
- 표의 API는 서버 경로. React 개발 프록시에서는 `/api` 접두어 사용.
- React의 `/payout/profiles`는 지급 계좌 프로필이며 **mdrl 언어 프로파일 화면이 아니다**.

## 4. 개발 연결 우선순위

1. 권리 검사: requirements·scope·grantor/grantee·공동권리자·의무·evidenceDigest를 팩/발행 화면에 연결.
2. 정산 추적: 이벤트 이용 맥락 → 판정 → 격리 → 재평가 → 원장의 연결을 상세 화면에 표시.
3. 정책 화면: Allocation 승인과 Grant 승인을 별도 업무로 표현; 프로파일 버전·지원 기능 표시.
4. 위임: 수령 Mandate와 이용허락 수권을 다른 화면·권한·증빙으로 처리.
5. 제품 운영: 테넌트·계약·QC·계정 관리·권리자/파트너 포털은 별도 구현 묶음으로 관리.
