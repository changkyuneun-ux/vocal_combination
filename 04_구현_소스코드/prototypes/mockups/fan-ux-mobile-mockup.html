① 보컬 조합 화면 — 기능 정의

허용된 곡·버전만 노출. 선택한 보컬을 탭하면 타겟 lane에 즉시 배정되고, 파형이 강조 상태로 전환됨. Ghost 이미지와 muted 파형으로 미배정 상태 시각화. 조합 규칙 엔진이 멤버 수·파트 중복·라이선스 조건을 백엔드에서 실시간 검증.

Stem 리스트 Ghost 이미지 보컬 선택 UI 파형 강조 조합 규칙 안내 피치 컨트롤

② 프리뷰 화면 — 기능 정의

오디오 엔진이 선택된 stem을 기준 버전에 얹어 실시간 프리뷰 생성. 볼륨·밸런스 슬라이더로 간단 튜닝 허용(복잡한 믹싱은 플랫폼 프리셋으로 처리). 발행 전 규칙·라이선스·권리 스냅샷 4개 항목 검증 체크리스트 자동 표시. 모두 통과 시 발행 단계로 진입.

실시간 재생 A/B 원곡 비교 믹스 슬라이더 구간 반복 검증 체크리스트

③ 발행 화면 — 기능 정의

조합 확정 시 고유 ID 자동 생성·권리 스냅샷 저장. 팬이 공개 범위·소장 옵션을 선택 후 최종 발행. 발행 완료 시 공유 링크 생성 및 "내 소장함" 자동 등록. 정산 엔진이 조합 ID와 매출 이벤트를 자동 연결해 IP 권리자·플랫폼·팬 인센티브 비율로 배분.
